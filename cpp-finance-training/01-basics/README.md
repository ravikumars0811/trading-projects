# Module 1: C++ Basics

## Topics Covered

1. Variables, Data Types, and Operators
2. Control Flow (if, switch, loops)
3. Functions and Function Overloading
4. Arrays and Strings
5. Pointers and References
6. Dynamic Memory Allocation
7. Basic I/O Operations

## Code Examples

Each topic includes working examples with financial/trading context.

### Files in This Module

1. `01_variables_datatypes.cpp` - Variables, types, and operators
2. `02_control_flow.cpp` - Conditional statements and loops
3. `03_functions.cpp` - Function basics and overloading
4. `04_arrays_strings.cpp` - Array manipulation and string operations
5. `05_pointers_references.cpp` - Pointer arithmetic and references
6. `06_dynamic_memory.cpp` - New/delete and memory management
7. `07_io_operations.cpp` - Input/output operations

## Compilation

```bash
g++ -std=c++17 -O2 -Wall -Wextra <filename.cpp> -o <output>
```

## Key Concepts to Master

- Understanding primitive data types for financial data
- Pointer arithmetic for efficient data access
- Memory management fundamentals
- Function design for reusability
